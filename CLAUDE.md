# Projeto
Este projeto é uma refatoração(proposta) do site institucional da unex, implementando uma arquitetura visual moderna, intuitiva e superior a atualmente usada no website.

## Tecnologias usadas
* React
* Typescript
* Tailwind CSS
* Vite

## Diretivas
* Sempre teste as funções após escrevê-las.
* Sempre siga as melhores práticas de desenvolvimento em TypeScript, respeitando as convenções.
* Os testes devem ser feitos em arquivos diferentes, um espelho do arquivo original, com o sufixo `test`.
* Sempre comente o que as funções fazem, qual é o objetivo do arquivo e a que ele se conecta.
* Segurança de dados e privacidade sempre em primeiro lugar.
* Arquitetura pensada para o github pages.
* Use como referencia de UI os arquivos de imagens no diretório `references`.
* Use o arquivo `demandas.md` em `references` para entender as demandas do projeto.
